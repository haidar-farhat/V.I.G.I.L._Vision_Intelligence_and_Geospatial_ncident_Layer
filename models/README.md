# Models

Operator-imported model artifacts live here. **Nothing in this directory is
committed**, and nothing is ever downloaded automatically.

Import through the application, which validates checksum, format, metadata,
supported runtime and hardware compatibility, and records the licence. Every event
the system generates names the model that produced its detections, so a detection
six months old can still be traced to the exact file.

See [docs/AI.md](../docs/AI.md).
